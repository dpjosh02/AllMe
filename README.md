# AllMe

AllMe is a personal operating system for daily notes, calendar visibility, finance tracking, and progress monitoring.

## Status

Foundation complete with an active finance prototype. The project is now moving through an architecture reset toward a full personal operating-system shell.

## Product Scope

The first version is a personal dashboard built around:

- daily notes and review
- Google Calendar-backed schedule views
- finance ingestion powered by Fintable and normalized into the app database
- progress tracking for habits, workouts, tasks, and custom metrics
